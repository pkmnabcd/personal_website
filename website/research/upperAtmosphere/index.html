Research with the USU Upper Atmospheric Imaging Lab

Since the summer of 2023, I have been working with Dr. Yucheng Zhao on the ALO and ANGWIN projects. With this group, I have presented two posters and written a senior project thesis. I have written software in C++, Java, bash, batch, python, and IDL. The code that I have written for my research is available at my Github repo.
I have been spending most of my time at this lab working with our ground-based imagers of the OH layer of the atmosphere (about 80 km altitude). I have identified clean windows of image data (without twilight, clouds, aurora, etc) and used that data to investigate the dynamics of the upper atmosphere. The frequent time gaps in the dataset made it so alternative analysis methods were sometimes needed.
My first major project was an investigation of planetary waves in the upper atmosphere caused by sudden stratospheric warming (SSW) events. For this, I analyzed global MERRA-2 assimilation model data. This involved acquiring the model data from NASA, extracting the relevant data, and analyzing it to determine potential properties of the resulting planetary wave. For this project, I developed an admittedly clumsy system (I was young) for doing the various analyses in bulk. The results of my research can be found on the poster: "Wave Properties of 2019 Southern SSW Event" (2024) that I presented on it.
My second major project was completed for my senior project. In this project, I used OH layer temperature data that was derived from our image data. I developed several algorithms to filter this data to remove unhelpful data (twilight, cloudy, etc). I also found strange irregularities in the data that required extra validation steps. Once the dataset was cleaned up, I plotted and analyzed the 14-year dataset, and I compared our dataset with a 10.7 cm solar flux dataset. I was able to find a strong correlation between the two datasets on the large scale. The results can be found in the poster: "Comparison of 15-Year OH Temperature Dataset with 10.7 cm Solar Flux" (2025) that I presented and the senior thesis: "Determining the Effect of Solar Activity on OH Temperature Above the Andes Lidar Observatory" (2025) that I wrote.
I am now doing a lot of image data analysis by identifying clean windows of data and analyzing it. We had preexisting methods of analyzing these windows that I have been working on automating. I automated the process of taking the set of clean windows and generating analysis plots by using python to hook with the existing code.
